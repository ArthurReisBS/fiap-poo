### Explicações sobre a classe "caderno"
- Essa foi a classe que escolhi para fazer a atividade passada, e a seguinte também.
- Nesta classe temos algumas características, sendo elas o título do caderno, localização do marca página e o total de folhas.
- Também temos alguns métodos, um que arranca folhas do caderno e o outro que modifica o local do marcador de páginas. Ambos os métodos exibem uma mensagem ao usuário se ele não tiver páginas o suficiente para fazer o que deseja. Exemplo: quer arrancar mais folhas que o total de folhas no caderno; quer marcar uma página maior que o total de folhas no caderno.

- Estou colocando isso nas explicações mas tudo é devidamente testado também no próprio código.
